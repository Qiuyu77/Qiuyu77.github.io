# 单层神经网络（逻辑回归）前向传播与反向传播

这份笔记对照你的手写稿做了三件事：保留已经算对的部分，改正符号和伪代码里的问题，并把中间被省略的代数补全。公式全部放在代码块里，方便直接对照着改笔记。

结论先说清楚：你推出的

```text
dz = a - y
```

是对的。批量梯度

```text
dw = (1/m) * X * dz^T
db = (1/m) * sum(dz)
w  := w - alpha * dw
b  := b - alpha * db
```

在「样本按列摆放」的约定下也是对的。需要改的是：损失 `L` 和代价 `J` 不要混成同一个符号、`dx` 不要写成 `dz`、单样本前向里的 `+ b` 不能放进点积括号里。

## 1. 笔记勘误

| 位置 | 原稿 | 问题 | 正确写法 |
|---|---|---|---|
| 开头 | `m` 个样本，特征下标又写成 `x_1 ... x_n` | `m` 和 `n` 容易打架 | 样本数用 `m`，特征维数用 `n_x` |
| ① | 先写 `dz = dL/dz`，再写 `da` | 只是定义，还不是计算结果；顺序反了 | 先算 `da`，再链式法则得到 `dz` |
| ④ | `dL/dw = x dz`，下一行又把带 `1/m` 的平均也叫成对 `L` 的导数 | 左边是单个损失 `L` 的梯度，右边是代价 `J` 的梯度 | 见第 5 节，两个符号分开 |
| 更新 | 公式里用 `η`，代码里用 `alpha` | 同一个学习率写了两个名字 | 统一写成 `alpha` |
| 单样本伪代码 | `z = np.dot(w.T, x + b)` | `b` 被加进了特征向量再做点积，模型变了 | `z = np.dot(w.T, x) + b` |
| 单样本伪代码 | 只有一步更新，没有循环 | 和右侧「多样本」不对称，看不出训练过程 | 外面包上迭代，或说明这只是一步 |
| 页边 | `dx` 不能和 `dz` 写在一起 | 这个提醒是对的，但原稿没写清 `dx` 是什么 | `dz = a - y` 用来更新 `w, b`；`dx = w * dz` 只在前面还有层时才需要，本层不更新 `x` |
| 实现 | 先写 `da = -y/a + (1-y)/(1-a)`，再乘 `a(1-a)` | 代数上对，数值上 `a→0` 或 `a→1` 会爆 | 代码里直接写 `dz = a - y`，不要走 `da` |

下面按「前向 → 损失 → 反向 → 更新 → 伪代码」重写一遍。

## 2. 符号和形状

一个样本是一个列向量。`m` 个样本把列横着拼成矩阵。这是后面 `dw = (1/m) * X * dz^T` 能成立的前提；如果有人把样本按行摆，转置就要反过来。

```text
n_x     特征个数
m       样本个数
x       一个样本, 形状 (n_x, 1)
        x = [x_1, x_2, ..., x_{n_x}]^T
X       全部样本, 形状 (n_x, m)
        第 i 列就是 x^{(i)}
y       一个标签, 标量, 取值 0 或 1
Y       全部标签, 形状 (1, m)
w       权重, 形状 (n_x, 1)
b       偏置, 标量
z       线性输出, 也叫 logit
a       sigmoid 之后的输出, 看成 P(y=1 | x)
alpha   学习率, 原稿里的 η 和 alpha 是同一个东西
```

第 `i` 个样本一律写成上标 `(i)`，不要和特征下标 `x_j` 混用。

```text
第 i 个样本:   x^{(i)}, y^{(i)}, z^{(i)}, a^{(i)}
第 j 个特征:   x_j, w_j
```

单层网络没有「上一层」，输入 `x` 是数据，不是要学习的参数。所以本层真正要回传给参数的是 `dz, dw, db`。`dx` 是另一条支路，第 6 节单独写。

## 3. 前向传播

### 3.1 一个样本

```text
z = w^T x + b
  = w_1 x_1 + w_2 x_2 + ... + w_{n_x} x_{n_x} + b

a = sigmoid(z)
  = 1 / (1 + exp(-z))
```

`z` 是任意实数。`a` 被压进 `(0, 1)`，当作「标签为 1」的概率。

偏置一定加在点积外面。这两种写法不相等：

```text
正确:  z = w^T x + b
错误:  z = w^T (x + b)
         = w^T x + b * (w_1 + w_2 + ... + w_{n_x})
```

错误写法等价于把每个特征都加上 `b`，再被全部权重加总。原稿左侧

```text
z = np.dot(w.T, x + b)
```

就是第二种。右侧多样本写成 `z = w^T X + b` 是对的，两侧要统一成这一种。

### 3.2 m 个样本，向量化

```text
Z = w^T X + b          形状 (1, m)
                       b 是标量, 自动加到每一列
A = sigmoid(Z)         形状 (1, m)
                       A 的第 i 列 = sigmoid(z^{(i)})
```

`w^T` 的形状是 `(1, n_x)`，`X` 的形状是 `(n_x, m)`，乘出来是 `(1, m)`。每一列是一个样本的 `z`，这一点你写在注释里了，是对的。

### 3.3 sigmoid 的导数

后面反向传播要用 `da/dz = a(1-a)`。这里把导数算完，避免只背结论。

```text
a = σ(z) = 1 / (1 + exp(-z))

令 u = 1 + exp(-z),  则 a = 1/u
du/dz = -exp(-z)

da/dz = d(u^{-1})/dz
      = - u^{-2} * du/dz
      = - u^{-2} * (-exp(-z))
      = exp(-z) / (1 + exp(-z))^2
```

把分子改写成「分母减 1」：

```text
exp(-z) = (1 + exp(-z)) - 1

da/dz = [ (1 + exp(-z)) - 1 ] / (1 + exp(-z))^2
      = 1/(1 + exp(-z)) - 1/(1 + exp(-z))^2
      = a - a^2
      = a (1 - a)
```

所以

```text
σ'(z) = a (1 - a)
```

因为 `a` 在 `(0, 1)` 里，这个导数总是正的，而且在 `a = 0.5` 时最大（等于 `0.25`），在饱和区接近 0。

## 4. 损失和代价

一个样本用二元交叉熵，也就是伯努利分布的负对数似然。你写的公式是对的：

```text
L(a, y) = - y * ln(a) - (1 - y) * ln(1 - a)
```

两个端点可以分开看，方便检查符号：

```text
y = 1 时:  L = - ln(a)        a 越接近 1, 损失越小
y = 0 时:  L = - ln(1 - a)    a 越接近 0, 损失越小
```

`m` 个样本的代价是损失的平均，不是再写一个新的 `L`：

```text
J(w, b) = (1/m) * Σ_{i=1}^{m} L(a^{(i)}, y^{(i)})
```

训练下降的是 `J`。只看一个样本时下降的是 `L`。梯度前面有没有 `1/m`，就由你到底在对谁求导决定。

## 5. 反向传播

固定一个样本，上标 `(i)` 先省掉。已知前向

```text
z = w^T x + b
a = σ(z)
L = - y ln(a) - (1 - y) ln(1 - a)
```

要求的是 `dL/dw` 和 `dL/db`。链式法则只走这条链：

```text
L ← a ← z ← w
            ← b
```

### 5.1 先对 a 求导

```text
L = - y * ln(a) - (1 - y) * ln(1 - a)

dL/da = - y * (1/a) - (1 - y) * (1/(1 - a)) * (-1)
      = - y / a + (1 - y) / (1 - a)
```

你的第 ② 步就是这一行，符号是对的。记

```text
da = dL/da = - y/a + (1 - y)/(1 - a)
```

这里的 `da` 是「损失对 a 的导数」，不是 `a` 的改变量。

### 5.2 再对 z 求导，并化成 a - y

```text
dz = dL/dz
   = (dL/da) * (da/dz)
   = da * a * (1 - a)
   = [ - y/a + (1 - y)/(1 - a) ] * a * (1 - a)
```

拆成两项。第一项消掉分母 `a`，第二项消掉分母 `1 - a`：

```text
第一项:  (- y / a) * a * (1 - a) = - y (1 - a)
第二项:  ( (1 - y) / (1 - a) ) * a * (1 - a) = (1 - y) * a
```

加在一起：

```text
dz = - y (1 - a) + (1 - y) a
   = - y + y a + a - y a
   = - y + a
   = a - y
```

`y a` 和 `- y a` 正好抵消。所以无论中间的 `da` 写得多吓人，单层逻辑回归的反向误差只有一句：

```text
dz = a - y
```

这就是你笔记里 `⇒ dz^{(i)} = a^{(i)} - y^{(i)}` 那一行，推导成立。

再写一条不先展开 `da` 的算法，用来交叉验证。利用

```text
σ'(z) / σ(z)       = 1 - a
σ'(z) / (1 - σ(z)) = a
```

则

```text
dL/dz = - y * (σ'/σ) + (1 - y) * (σ' / (1 - σ))
      = - y (1 - a) + (1 - y) a
      = a - y
```

两条路结果相同。

数值上不要实现成「先算 `da` 再乘 `a(1-a)`」。`a` 接近 0 或 1 时，`-y/a` 和 `(1-y)/(1-a)` 会溢出，但它们和 `a(1-a)` 相乘后的极限就是 `a - y`，是有限的。代码直接写 `dz = a - y`。

### 5.3 对 w 和 b 求导（一个样本）

```text
z = w_1 x_1 + ... + w_{n_x} x_{n_x} + b

dz/dw_j = x_j
dz/db   = 1
```

所以每个分量

```text
dL/dw_j = (dL/dz) * (dz/dw_j) = dz * x_j
dL/db   = (dL/dz) * (dz/db)   = dz
```

合成向量（`dz` 是标量，乘在列向量 `x` 上）：

```text
dL/dw = x * dz          形状 (n_x, 1)
dL/db = dz              标量
```

你写的 `dL/dw = x^{(i)} dz^{(i)}`、`dL/db = dz^{(i)}` 指的就是这个，针对第 `i` 个样本的损失 `L`，不是针对平均代价 `J`。

### 5.4 对代价 J 求导（m 个样本）

```text
J = (1/m) * Σ_{i=1}^{m} L(a^{(i)}, y^{(i)})
```

求导和求和、乘常数都可以交换：

```text
dJ/dw = (1/m) * Σ_{i=1}^{m} ( dL^{(i)}/dw )
      = (1/m) * Σ_{i=1}^{m} x^{(i)} * dz^{(i)}

dJ/db = (1/m) * Σ_{i=1}^{m} dz^{(i)}
```

其中每个样本仍用已经化简过的误差：

```text
dz^{(i)} = a^{(i)} - y^{(i)}
```

把样本按列堆好之后，求和就是一次矩阵乘法：

```text
X  的形状 (n_x, m)
dz 的形状 (1, m)      也就是行向量 [dz^{(1)}, ..., dz^{(m)}]
dz^T 的形状 (m, 1)

dJ/dw = (1/m) * X * dz^T     形状 (n_x, 1)
dJ/db = (1/m) * Σ_i dz^{(i)}  标量
```

核对形状：`(n_x, m)` 乘 `(m, 1)` 得到 `(n_x, 1)`，和 `w` 同形，才能相减。你原稿右侧

```text
dw = (1/m) * X · dz^T
db = (1/m) * sum(dz)
```

就是 `dJ/dw` 和 `dJ/db`。不要再把它们叫成 `dL/dw`。差的就是那个 `1/m`，漏掉或多写一次，步长会差 `m` 倍。

### 5.5 梯度下降

沿代价下降，所以是减梯度，不是加梯度：

```text
w := w - alpha * dJ/dw
b := b - alpha * dJ/db
```

只在一个样本的损失 `L` 上走一步时（随机梯度，或本来就只有 1 个样本）：

```text
w := w - alpha * (x * dz)
b := b - alpha * dz
```

这两种更新不要混用。批量用了 `1/m` 之后，`alpha` 的合适量级和「单样本不除以 `m`」不一样。

逻辑回归的 `J` 对 `(w, b)` 是凸的，`w = 0`、`b = 0` 是合法初始值。深层网络才必须把权重随机初始化来打破对称；这一层没有隐藏单元，不存在对称性要打破。

## 6. dx 和 dz 为什么不能写成同一个东西

参数更新只用到 `dz`：

```text
dz = dL/dz = a - y
dw = x * dz
db = dz
```

如果还要把误差传回输入（这一层前面又接了别的层），输入的梯度是另一条链式法则：

```text
z = w^T x + b
dL/dx = (dL/dz) * (dz/dx) = w * dz
```

形状：`w` 是 `(n_x, 1)`，`dz` 是标量，所以 `dx` 也是 `(n_x, 1)`。

```text
dx = w * dz          形状和 x 相同
dz = a - y           标量
```

二者不相等。`x` 是观测到的数据，单层逻辑回归不更新 `x`，所以这份笔记的训练步骤里不出现 `dx`。把它和 `dz` 并列写进同一次参数更新，是错的。

## 7. 伪代码

下面两段都用同一套形状：`x` 和 `w` 是列向量，`X` 的每一列是一个样本。学习率统一叫 `alpha`。

### 7.1 一个样本，重复下降

原稿左侧把 `b` 加进了点积，也没有迭代。改正如下。

```text
输入:
    x          形状 (n_x, 1)
    y          标量, 0 或 1
    alpha      学习率
    num_steps  在这个样本上走多少步

初始化:
    w = zeros(n_x, 1)
    b = 0

for step = 1 to num_steps:
    # 前向。b 在点积外面
    z = dot(w^T, x) + b          # 标量
    a = 1 / (1 + exp(-z))        # 标量

    # 反向。不要先算 da
    dz = a - y                   # 标量
    dw = x * dz                  # (n_x, 1)，这是 dL/dw
    db = dz                      # 标量，这是 dL/db

    # 更新
    w = w - alpha * dw
    b = b - alpha * db
```

对应的 numpy 形状也写死，避免 `(1, 1)` 和 Python 标量混用时看不清：

```text
z  = np.dot(w.T, x) + b          # 不要写成 np.dot(w.T, x + b)
a  = 1 / (1 + np.exp(-z))
dz = a - y
dw = x * dz
db = dz
w  = w - alpha * dw
b  = b - alpha * db
```

如果 `m = 1`，这里的 `dw` 就等于代价的梯度。如果这是从很多样本里抽一个做随机梯度，这里的 `dw` 是 `dL/dw`，没有 `1/m`。

### 7.2 m 个样本，批量梯度下降

原稿右侧的矩阵公式是对的，补上初始化、sigmoid 的定义，以及每一步是在对 `J` 求导。

```text
输入:
    X            形状 (n_x, m)，第 i 列是 x^{(i)}
    Y            形状 (1, m)
    alpha        学习率
    num_iters    迭代次数

初始化:
    w = zeros(n_x, 1)
    b = 0

for iter = 1 to num_iters:
    # 前向
    Z = dot(w^T, X) + b                 # (1, m)
    A = 1 / (1 + exp(-Z))               # (1, m)

    # 反向
    dZ = A - Y                          # (1, m)
    dw = (1/m) * dot(X, dZ^T)           # (n_x, 1) = dJ/dw
    db = (1/m) * sum(dZ)                # 标量   = dJ/db

    # 更新
    w = w - alpha * dw
    b = b - alpha * db
```

numpy 写法，和上面一一对应：

```text
Z  = np.dot(w.T, X) + b
A  = 1 / (1 + np.exp(-Z))
dZ = A - Y
dw = (1/m) * np.dot(X, dZ.T)
db = (1/m) * np.sum(dZ)
w  = w - alpha * dw
b  = b - alpha * db
```

可选：每一轮把代价记下来，确认它总体在下降。

```text
J = -(1/m) * sum( Y*ln(A) + (1-Y)*ln(1-A) )
```

`A` 非常接近 0 或 1 时，`ln(A)` 会溢出。需要稳定实现时，把 `A` 裁剪到一个很小的开区间再取对数，例如 `[1e-15, 1-1e-15]`。梯度仍然用 `dZ = A - Y`，不要改成裁剪之后再手算 `da`。

### 7.3 预测

训练完只用前向，不再反向：

```text
z = dot(w^T, x) + b
a = 1 / (1 + exp(-z))
y_hat = 1    若 a >= 0.5
y_hat = 0    若 a <  0.5
```

`0.5` 是默认阈值。`a` 本身就是预测概率，不必再过一次阈值才能拿来算损失；阈值只用于给出 0/1 类别。

## 8. 手算一遍，核对 a - y 和向量化

### 8.1 一个样本：确认 da * a(1-a) 等于 a - y

```text
x = [1, 2]^T
y = 1
w = [0, 0]^T
b = 0
```

前向：

```text
z = 0*1 + 0*2 + 0 = 0
a = 1 / (1 + exp(0)) = 0.5
```

走你笔记里的长公式：

```text
da = - y/a + (1-y)/(1-a)
   = - 1/0.5 + 0/0.5
   = -2

a(1-a) = 0.5 * 0.5 = 0.25

dz = da * a(1-a) = -2 * 0.25 = -0.5
```

走化简公式：

```text
dz = a - y = 0.5 - 1 = -0.5
```

一致。接着

```text
dw = x * dz = [1, 2]^T * (-0.5) = [-0.5, -1]^T
db = -0.5
```

取 `alpha = 0.1`：

```text
w = [0, 0]^T - 0.1 * [-0.5, -1]^T = [0.05, 0.1]^T
b = 0 - 0.1 * (-0.5) = 0.05
```

标签是 1，当前概率只有 0.5，两个特征又都是正的，所以 `w` 和 `b` 都变大，下一步 `z` 会变大、`a` 会更靠近 1。方向正确。

### 8.2 两个样本：确认 (1/m) X dz^T 等于逐样本相加

```text
x^{(1)} = [1, 2]^T    y^{(1)} = 1
x^{(2)} = [3, 0]^T    y^{(2)} = 0

X = | 1  3 |          Y = | 1  0 |
    | 2  0 |

w = [0, 0]^T
b = 0
```

前向两次都是 `z = 0`，所以

```text
A  = | 0.5  0.5 |
dZ = A - Y = | 0.5-1 ,  0.5-0 | = | -0.5  0.5 |
```

向量化：

```text
dZ^T = | -0.5 |
       |  0.5 |

X * dZ^T = | 1*(-0.5) + 3*(0.5) | = | 1.0 |
           | 2*(-0.5) + 0*(0.5) |   |-1.0 |

dw = (1/2) * | 1.0 | = | 0.5 |
             |-1.0 |   |-0.5 |

db = (1/2) * (-0.5 + 0.5) = 0
```

逐样本相加：

```text
dw = (1/2) * ( x^{(1)}*(-0.5) + x^{(2)}*(0.5) )
   = (1/2) * ( [-0.5, -1]^T + [1.5, 0]^T )
   = (1/2) * [1, -1]^T
   = [0.5, -0.5]^T
```

和矩阵乘法一致。这就是原稿右侧 `dw = (1/m) * X · dz^T` 在数字上的含义。

## 9. 可以背下来的计算顺序

```text
前向
    z = w^T x + b
    a = 1 / (1 + exp(-z))

一个样本的损失
    L = - y ln(a) - (1-y) ln(1-a)

m 个样本的代价
    J = (1/m) * Σ L_i

反向（不要停留在 da）
    dz = a - y
    dL/dw = x * dz
    dL/db = dz

批量梯度
    dJ/dw = (1/m) * Σ x^{(i)} dz^{(i)} = (1/m) * X * dz^T
    dJ/db = (1/m) * Σ dz^{(i)}

更新
    w = w - alpha * dJ/dw
    b = b - alpha * dJ/db

传给上一层时才需要，本层训练用不到
    dx = w * dz
```
