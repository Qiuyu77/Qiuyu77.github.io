# 单层神经网络：逻辑回归的前向传播与反向传播

单层神经网络做二分类时，就是逻辑回归。前向先算线性结果 `z`，再经 sigmoid 得到概率 `a`。训练用二元交叉熵。对这个损失求梯度时，中间项会消掉，反向误差只剩 `a - y`。本文把前向、损失、反向、向量化和伪代码按同一种形状约定写完整。

---

## 1. 模型

输入是特征向量，输出是「标签为 1」的概率。参数只有权重 `w` 和偏置 `b`。

```text
z = w^T x + b
a = sigmoid(z) = 1 / (1 + exp(-z))
```

`z` 可以是任意实数。`a` 落在开区间 `(0, 1)`。

判决用阈值 `0.5`，它和 `z` 的符号是同一件事：

```text
a >= 0.5  当且仅当  z >= 0
y_hat = 1  当 z >= 0
y_hat = 0  当 z <  0
```

因此分界面是一张超平面：

```text
w^T x + b = 0
```

计算图只有一条链：

```text
x ──┐
w ──┼──► z = w^T x + b ──► a = sigmoid(z) ──► L(a, y)
b ──┘                                         ▲
                                              │
                                              y
```

参数更新走 `L → a → z → w` 和 `L → a → z → b`。输入 `x` 是数据，不是参数。`dx` 只在这一层前面还接着别的层时才需要，见第 8 节。

---

## 2. 符号与形状

样本按列摆放。后面的矩阵乘法都依赖这个约定。

```text
n_x     特征个数
m       样本个数

x       一个样本, 列向量, 形状 (n_x, 1)
X       全部样本, 形状 (n_x, m), 第 i 列是 x^{(i)}
y       一个标签, 标量, 只取 0 或 1
Y       全部标签, 形状 (1, m)

w       权重, 形状 (n_x, 1)
b       偏置, 标量
z, Z    线性输出。单个样本是标量, 全部样本形状 (1, m)
a, A    sigmoid 输出。形状与 z, Z 相同
alpha   学习率
```

上标表示样本，下标表示特征，二者不混用：

```text
第 i 个样本:  x^{(i)}, y^{(i)}, z^{(i)}, a^{(i)}
第 j 个特征:  x_j, w_j
```

一个样本写成向量就是：

```text
x = [x_1, x_2, ..., x_{n_x}]^T
w = [w_1, w_2, ..., w_{n_x}]^T

z = w_1 x_1 + w_2 x_2 + ... + w_{n_x} x_{n_x} + b
```

---

## 3. 前向传播

### 3.1 一个样本

```text
z = w^T x + b
a = 1 / (1 + exp(-z))
```

偏置加在点积外面。它和「先把 `b` 加进每个特征再做点积」不是同一个模型：

```text
正确:  z = w^T x + b

错误:  z = w^T (x + b)
         = w^T x + b * (w_1 + ... + w_{n_x})
```

第二种把每个特征都平移了 `b`，再被全部权重加总。代码里必须写成点积完成之后再加 `b`。

### 3.2 m 个样本

```text
Z = w^T X + b        形状 (1, m)
A = sigmoid(Z)       形状 (1, m)
```

`w^T` 是 `(1, n_x)`，`X` 是 `(n_x, m)`，乘积是 `(1, m)`。每一列对应一个样本。标量 `b` 加到每一列上。

---

## 4. Sigmoid 的导数

反向传播要用 `da/dz`。设

```text
a = 1 / (1 + exp(-z))
u = 1 + exp(-z)
a = u^{-1}
du/dz = -exp(-z)
```

求导：

```text
da/dz = - u^{-2} * du/dz
      = exp(-z) / (1 + exp(-z))^2
```

分子改写成「分母减 1」：

```text
exp(-z) = (1 + exp(-z)) - 1

da/dz = [ (1 + exp(-z)) - 1 ] / (1 + exp(-z))^2
      = 1/(1 + exp(-z)) - 1/(1 + exp(-z))^2
      = a - a^2
      = a (1 - a)
```

结论：

```text
sigmoid'(z) = a (1 - a)
```

`a` 在 `(0, 1)` 内，导数恒正。`a = 0.5` 时导数最大，等于 `0.25`。`a` 靠近 0 或 1 时导数靠近 0，这就是饱和。

两个后面化简要用的比值：

```text
sigmoid'(z) / a         = 1 - a
sigmoid'(z) / (1 - a)   = a
```

---

## 5. 损失函数

### 5.1 一个样本：负对数似然

把 `a` 当作伯努利分布的参数：

```text
P(y | x) = a^y * (1 - a)^(1 - y)
```

对数似然：

```text
ln P(y | x) = y * ln(a) + (1 - y) * ln(1 - a)
```

损失取负号，最小化损失就等于最大化似然：

```text
L(a, y) = - y * ln(a) - (1 - y) * ln(1 - a)
```

两种标签下它各自退化成一项：

```text
y = 1:   L = - ln(a)        a 越靠近 1, L 越小
y = 0:   L = - ln(1 - a)    a 越靠近 0, L 越小
```

### 5.2 m 个样本：代价

样本独立同分布时，总对数似然是各项之和。代价取平均，数值大小不随 `m` 成比例膨胀，学习率更好选：

```text
J(w, b) = (1/m) * Σ_{i=1}^{m} L(a^{(i)}, y^{(i)})
```

`L` 是一个样本的损失。`J` 是全部样本的平均代价。梯度前有没有 `1/m`，取决于求导对象是 `L` 还是 `J`。

---

## 6. 反向传播

下面先固定一个样本，省去上标 `(i)`。已知

```text
z = w^T x + b
a = sigmoid(z)
L = - y * ln(a) - (1 - y) * ln(1 - a)
```

### 6.1 对 a 求导

```text
dL/da = - y * (1/a) - (1 - y) * [1/(1 - a)] * (-1)
      = - y / a + (1 - y) / (1 - a)
```

记

```text
da = dL/da = - y/a + (1 - y)/(1 - a)
```

这里的 `da` 是导数，不是 `a` 的增量。

### 6.2 对 z 求导，化成 a - y

链式法则：

```text
dz = dL/dz
   = (dL/da) * (da/dz)
   = [ - y/a + (1 - y)/(1 - a) ] * a * (1 - a)
```

拆开，分母分别被消掉：

```text
第一项:  (- y / a) * a * (1 - a) = - y (1 - a)
第二项:  [ (1 - y) / (1 - a) ] * a * (1 - a) = (1 - y) a
```

相加：

```text
dz = - y (1 - a) + (1 - y) a
   = - y + y a + a - y a
   = a - y
```

`y a` 与 `- y a` 抵消。因此

```text
dz = a - y
```

另一条路不展开 `da`，用第 4 节的比值：

```text
dL/dz = - y * (sigmoid'(z) / a) + (1 - y) * (sigmoid'(z) / (1 - a))
      = - y (1 - a) + (1 - y) a
      = a - y
```

两条路结果相同。

这个消元只对「sigmoid + 二元交叉熵」成立。如果损失改成平方误差，链式法则里的 `a(1-a)` 消不掉：

```text
L_sq = (1/2) * (a - y)^2
dL_sq/dz = (a - y) * a * (1 - a)
```

不能把平方误差的反向也写成 `a - y`。

实现时不要先算 `da` 再乘 `a(1-a)`。`a` 靠近 0 或 1 时，`-y/a` 和 `(1-y)/(1-a)` 会溢出，乘回去之后的极限才是有限的 `a - y`。代码直接使用化简结果。

### 6.3 对 w 和 b 求导

```text
z = w_1 x_1 + ... + w_{n_x} x_{n_x} + b

dz/dw_j = x_j
dz/db   = 1
```

所以

```text
dL/dw_j = dz * x_j
dL/db   = dz
```

`dz` 是标量，乘在列向量上：

```text
dL/dw = x * dz       形状 (n_x, 1)
dL/db = dz           标量
```

分量形式就是 `dw_j = x_j * (a - y)`。预测高于标签时 `a - y > 0`，该特征为正就会把对应权重往下拉。

---

## 7. 批量梯度与向量化

### 7.1 代价的梯度

```text
J = (1/m) * Σ_{i=1}^{m} L(a^{(i)}, y^{(i)})
dz^{(i)} = a^{(i)} - y^{(i)}
```

求和与乘常数可以和求导交换：

```text
dJ/dw = (1/m) * Σ_{i=1}^{m} x^{(i)} * dz^{(i)}
dJ/db = (1/m) * Σ_{i=1}^{m} dz^{(i)}
```

第 `j` 个权重：

```text
dJ/dw_j = (1/m) * Σ_{i=1}^{m} x_j^{(i)} * (a^{(i)} - y^{(i)})
```

左边这些是 `J` 的梯度，不是某一个 `L` 的梯度。单个 `L` 的梯度没有前面的 `1/m`。

### 7.2 矩阵形式

```text
X    形状 (n_x, m)
dZ   形状 (1, m),  即 [dz^{(1)}, ..., dz^{(m)}]
dZ^T 形状 (m, 1)

dJ/dw = (1/m) * X * dZ^T      形状 (n_x, 1)
dJ/db = (1/m) * sum(dZ)       标量
```

形状对得上，结果才能和 `w`、`b` 相减：`(n_x, m)` 乘 `(m, 1)` 得到 `(n_x, 1)`。

它和逐样本求和是同一件事。`X * dZ^T` 的第 `j` 行等于

```text
Σ_{i=1}^{m} X_{j,i} * dz^{(i)}
```

再除以 `m`，就是上一节的 `dJ/dw_j`。

若样本被摆成行，即矩阵形状是 `(m, n_x)`，转置位置要整段对调，不能只改其中一次乘法。

---

## 8. dx 与 dz

更新 `w` 和 `b` 只用 `dz`：

```text
dz = a - y
dw = x * dz
db = dz
```

误差若还要传回输入，走另一条链：

```text
dL/dx = (dL/dz) * (dz/dx) = w * dz
```

```text
dx = w * dz       形状 (n_x, 1), 与 x 相同
dz = a - y        标量
```

`dx` 不等于 `dz`，也不能拿去更新 `w`。单层逻辑回归里 `x` 是观测值，训练步骤不出现 `dx`。

---

## 9. 参数更新

沿梯度下降，用减号：

```text
w := w - alpha * dJ/dw
b := b - alpha * dJ/db
```

三种用法对应三种梯度，不要混用系数：

```text
批量梯度下降
    用整批样本的 dJ/dw、dJ/db
    其中已经包含 1/m
    这是 J 的精确梯度

随机梯度下降
    随机抽一个样本 i
    dw = x^{(i)} * dz^{(i)}
    db = dz^{(i)}
    这是 dL/dw，不要再除以 m
    它是 dJ 的无偏估计：每个样本等概率抽取时，E[dL/dw] = dJ/dw

小批量
    设这个小批有 m_b 个样本
    dw = (1/m_b) * X_batch * dZ_batch^T
    db = (1/m_b) * sum(dZ_batch)
```

漏掉批量公式里的 `1/m`，相当于用了 `m` 倍的梯度，步长会被放大 `m` 倍。随机梯度本身就不再除以 `m`，那不是漏项。

`J` 关于 `(w, b)` 是凸函数。初值可以取

```text
w = 0
b = 0
```

这一层没有多个隐藏单元，不需要用随机初始化去打破对称。深层网络才需要。

## 10. 伪代码

约定：`w`、`x` 为列向量，`X` 的每一列是一个样本。

### 10.1 单个样本上走若干步

只有一个样本时，`m = 1`，`dL` 和 `dJ` 相同。

```text
输入:
    x          形状 (n_x, 1)
    y          标量, 0 或 1
    alpha      学习率
    num_steps  迭代步数

初始化:
    w = zeros(n_x, 1)
    b = 0

for step = 1 to num_steps:
    z  = dot(w^T, x) + b
    a  = 1 / (1 + exp(-z))

    dz = a - y
    dw = x * dz
    db = dz

    w  = w - alpha * dw
    b  = b - alpha * db
```

对应的数组写法：

```text
z  = np.dot(w.T, x) + b
a  = 1 / (1 + np.exp(-z))
dz = a - y
dw = x * dz
db = dz
w  = w - alpha * dw
b  = b - alpha * db
```

`b` 在点积外面。`np.dot(w.T, x + b)` 是错的。

### 10.2 全部样本的批量梯度下降

```text
输入:
    X          形状 (n_x, m)
    Y          形状 (1, m)
    alpha
    num_iters

初始化:
    w = zeros(n_x, 1)
    b = 0

for iter = 1 to num_iters:
    Z  = dot(w^T, X) + b                  # (1, m)
    A  = 1 / (1 + exp(-Z))                # (1, m)

    dZ = A - Y                            # (1, m)
    dw = (1/m) * dot(X, dZ^T)             # (n_x, 1)
    db = (1/m) * sum(dZ)                  # 标量

    w  = w - alpha * dw
    b  = b - alpha * db
```

```text
Z  = np.dot(w.T, X) + b
A  = 1 / (1 + np.exp(-Z))
dZ = A - Y
dw = (1/m) * np.dot(X, dZ.T)
db = (1/m) * np.sum(dZ)
w  = w - alpha * dw
b  = b - alpha * db
```

每一轮可以记录代价，用来确认整体在下降：

```text
J = -(1/m) * sum( Y * ln(A) + (1 - Y) * ln(1 - A) )
```

`A` 极靠近 0 或 1 时对数会溢出。计算 `J` 之前把 `A` 裁到一个小的开区间，例如 `[1e-15, 1 - 1e-15]`。梯度仍用 `dZ = A - Y`，不要改回 `da` 那条不稳定的式子。

### 10.3 按样本循环的随机梯度下降

```text
初始化:
    w = zeros(n_x, 1)
    b = 0

for epoch = 1 to num_epochs:
    将样本下标 1..m 随机打乱
    for i in 打乱后的顺序:
        z  = dot(w^T, x^{(i)}) + b
        a  = 1 / (1 + exp(-z))
        dz = a - y^{(i)}
        dw = x^{(i)} * dz          # 不再乘 1/m
        db = dz

        w  = w - alpha * dw
        b  = b - alpha * db
```

### 10.4 预测

预测只有前向，没有损失，也没有参数更新：

```text
z = dot(w^T, x) + b
a = 1 / (1 + exp(-z))

y_hat = 1    若 a >= 0.5
y_hat = 0    若 a <  0.5
```

`a` 是概率。交叉熵直接使用 `a`，不要先把 `a` 变成 0/1 再拿去算损失。0/1 只用于给出类别。

## 11. 数值演算

### 11.1 一个样本：核对 da * a(1-a) = a - y

```text
x = [1, 2]^T
y = 1
w = [0, 0]^T
b = 0
```

前向：

```text
z = 0
a = 1 / (1 + exp(0)) = 1/2
```

先走未化简的式子：

```text
da = - y/a + (1 - y)/(1 - a)
   = - 1/(1/2) + 0
   = -2

a(1 - a) = (1/2) * (1/2) = 1/4

dz = da * a(1 - a) = -2 * (1/4) = -1/2
```

再走化简式：

```text
dz = a - y = 1/2 - 1 = -1/2
```

一致。参数梯度：

```text
dw = x * dz = [1, 2]^T * (-1/2) = [-1/2, -1]^T
db = -1/2
```

学习率 `alpha = 0.1` 时，一步更新为：

```text
w = [0, 0]^T - 0.1 * [-1/2, -1]^T = [0.05, 0.1]^T
b = 0 - 0.1 * (-1/2) = 0.05
```

标签是 1，当前概率只有 `0.5`，两个特征都是正数，所以 `w` 和 `b` 都增大。下一步 `z` 变大，`a` 会靠近 1。

用链式法则直接看 `w_1`，可以再核对一次符号和数值：

```text
dL/da = -2
da/dz = 1/4
dz/dw_1 = x_1 = 1

dL/dw_1 = -2 * (1/4) * 1 = -1/2
```

与 `dw` 的第一个分量相同。

### 11.2 两个样本：核对矩阵乘法和逐项求和

```text
x^{(1)} = [1, 2]^T     y^{(1)} = 1
x^{(2)} = [3, 0]^T     y^{(2)} = 0

X = | 1  3 |
    | 2  0 |

Y = | 1  0 |

w = [0, 0]^T
b = 0
m = 2
```

两个样本的线性输出都是 0：

```text
A  = | 1/2   1/2 |
dZ = | 1/2 - 1 ,  1/2 - 0 | = | -1/2   1/2 |
```

矩阵形式：

```text
dZ^T = | -1/2 |
       |  1/2 |

X * dZ^T = | 1*(-1/2) + 3*(1/2) | = |  1 |
           | 2*(-1/2) + 0*(1/2) |   | -1 |

dw = (1/2) * |  1 | = |  1/2 |
             | -1 |   | -1/2 |

db = (1/2) * (-1/2 + 1/2) = 0
```

逐样本相加：

```text
dw = (1/2) * ( x^{(1)} * (-1/2) + x^{(2)} * (1/2) )
   = (1/2) * ( [-1/2, -1]^T + [3/2, 0]^T )
   = (1/2) * [1, -1]^T
   = [1/2, -1/2]^T
```

两种算法相同。

## 12. 实现时对照

```text
单个样本
    z  = dot(w^T, x) + b          标量
    a  = sigmoid(z)               标量
    dz = a - y                    标量
    dw = x * dz                   (n_x, 1)
    db = dz                       标量

全部样本
    Z  = dot(w^T, X) + b          (1, m)
    A  = sigmoid(Z)               (1, m)
    dZ = A - Y                    (1, m)
    dw = (1/m) * dot(X, dZ^T)     (n_x, 1)
    db = (1/m) * sum(dZ)          标量

传回上一层，本层训练不用
    dx = w * dz                   (n_x, 1)
```

容易写错的几处：

```text
1. b 必须写在点积外面。
2. dL/dw = x * dz 是一个样本的梯度。
   dJ/dw = (1/m) * X * dZ^T 是平均代价的梯度。
3. 批量梯度漏掉 1/m，步长会放大 m 倍。
   随机梯度使用单个样本的 dL/dw，本来就没有 1/m。
4. dx = w * dz，dz = a - y。二者不是同一个量。
5. dz = a - y 只属于 sigmoid 加二元交叉熵。
6. 样本按列存放时，dZ 是 (1, m)，乘法是 X * dZ^T。
   把 dZ 当成列向量再右乘，形状会错。
7. 计算 J 时对 A 做裁剪；反向仍写 dZ = A - Y。
```

## 13. 公式汇总

```text
前向
    z = w^T x + b
    a = 1 / (1 + exp(-z))
    sigmoid'(z) = a (1 - a)

一个样本
    L = - y ln(a) - (1 - y) ln(1 - a)

m 个样本
    J = (1/m) * Σ_{i=1}^{m} L(a^{(i)}, y^{(i)})

反向
    dL/da = - y/a + (1 - y)/(1 - a)
    dL/dz = (dL/da) * a * (1 - a) = a - y
    dL/dw = x * (a - y)
    dL/db = a - y

批量
    dJ/dw = (1/m) * Σ_{i=1}^{m} x^{(i)} (a^{(i)} - y^{(i)})
          = (1/m) * X * dZ^T
    dJ/db = (1/m) * Σ_{i=1}^{m} (a^{(i)} - y^{(i)})

更新
    w := w - alpha * dJ/dw
    b := b - alpha * dJ/db

上一层才使用
    dx = w * (a - y)

预测
    y_hat = 1  当 w^T x + b >= 0
    y_hat = 0  当 w^T x + b <  0
```
